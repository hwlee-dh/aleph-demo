# aleph-demo

이 리포지토리는 [ALEPH](https://github.com/hwlee-dh/aleph) 발표 자료와 데모를 올려 두기 위한 임시 리포입니다.

발표 자료(GitHub Pages): <https://hwlee-dh.github.io/aleph-demo/>

```
index.html     들머리
slides/        발표 자료
demo/          데모 (준비 중)
tools/         QR 그림을 만드는 스크립트
assets/        폰트, 그림, 공통 스타일
```

## 발표 자료

| 조작 | 키 |
| --- | --- |
| 다음 | `→`, `Space`, `Enter`, 클릭 |
| 이전 | `←`, `Backspace`, 화면 왼쪽 끝 클릭 |
| 처음, 끝 | `Home`, `End` |
| 전체 화면 | `F` |

모바일 화면 등에서는 스와이프로 조작합니다. 주소 끝에 적힌 `#장.단계`가 현재 페이지입니다.
